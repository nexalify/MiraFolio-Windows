## 모든 디스플레이를 위한 더 나은 배경화면 경험

- **디스플레이별 독립 제어.** 각 모니터마다 이미지 폴더, 순환 간격, 재생 순서와 활성화 여부를 따로 설정할 수 있습니다.
- **수만 장의 배경화면을 위한 설계.** 폴더를 백그라운드에서 인덱싱하고 이미지 정보를 캐시하므로 시작할 때마다 이미지 크기를 다시 읽지 않습니다.
- **감상하면서 컬렉션 정리.** 마음에 들지 않는 배경화면은 원본 파일을 삭제하지 않고 한 번의 클릭으로 이후 순환에서 제외하고, 휴지통에서 다시 복원할 수 있습니다.
- **구성이 바뀌어도 안정적.** 디스플레이 하나를 분리해도 나머지 화면이 숨겨지거나 중단되지 않으며, Windows가 새 디스플레이를 감지하면 바로 설정할 수 있습니다.
- **더 똑똑한 이미지 선택.** 가로 이미지는 가로 화면에, 세로 이미지는 세로 화면에 맞추고 너무 작은 이미지는 건너뜁니다.
- **처음부터 개인정보 보호 중심.** MiraFolio는 계정, 클라우드 서비스, 분석 기능, 배경화면 업로드 없이 로컬에서 작동합니다.

## 주요 기능

- 중복 없는 무작위, 정방향 또는 역방향으로 배경화면 순환.
- 게임, 프레젠테이션, 동영상이 전체 화면일 때 해당 디스플레이의 순환만 일시 정지.
- 빠른 작업으로 현재 배경화면 변경, 파일 위치 열기 또는 순환에서 제외.
- 제외한 이미지를 휴지통에서 검토하고 복원하거나, 명시적으로 확인한 후에만 영구 삭제.
- Windows와 함께 시작하고 알림 영역에서 일상적인 기능 제어.
- 가로 및 세로 디스플레이가 섞인 구성을 하나의 시각적 레이아웃에서 관리.

## 다운로드 및 실행

[최신 MiraFolio Release](https://github.com/nexalify/MiraFolio-Windows/releases/latest)를 열고
**Assets**를 펼친 다음 `MiraFolio-<version>-win-x64-portable.zip`을 다운로드하세요. 현재 정식 버전의
파일 이름은 `MiraFolio-1.0.0-win-x64-portable.zip`입니다. ZIP을 계속 사용할 폴더에 압축 해제한 뒤
`MiraFolio.exe`를 실행하세요. 설치나 별도의 .NET 런타임은 필요하지 않습니다.

## 시작하기

1. MiraFolio를 열고 시각적 모니터 레이아웃에서 디스플레이를 선택합니다.
2. 해당 디스플레이에 사용할 배경화면 폴더를 선택합니다.
3. 순환 간격, 재생 순서 및 스마트 매칭 옵션을 설정합니다.
4. 순환을 활성화합니다. MiraFolio는 알림 영역에서 계속 실행됩니다.

맞춤 설정할 다른 디스플레이가 있다면 처음 세 단계를 반복하세요.

## 시스템 요구 사항

- Windows 10 또는 Windows 11
- x64 PC
- 공식 자체 포함 버전에는 별도의 .NET 설치가 필요하지 않음
