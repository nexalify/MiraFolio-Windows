## すべてのディスプレイに、より良い壁紙体験を

- **ディスプレイごとに独立して管理。** 画像フォルダー、切り替え間隔、再生順序、有効・無効をモニターごとに設定できます。
- **数万枚規模の壁紙に対応。** フォルダーをバックグラウンドでインデックス化し、画像情報をキャッシュするため、起動のたびにサイズを読み直す必要がありません。
- **眺めながらコレクションを整理。** 気に入らない壁紙は、元ファイルを削除せずにワンクリックで今後のローテーションから外せます。ごみ箱からの復元も可能です。
- **構成が変わっても安定動作。** 1 台を切断してもほかの画面は非表示にならず、動作も止まりません。Windows が新しいディスプレイを認識すれば、すぐに設定できます。
- **より賢い画像選択。** 横長画像を横向き画面に、縦長画像を縦向き画面に合わせ、サイズが小さすぎる画像を除外できます。
- **プライバシーを重視。** MiraFolio はアカウント、クラウドサービス、アクセス解析、壁紙のアップロードなしでローカル動作します。

## 主な機能

- 重複なしのランダム、順送り、逆送りで壁紙を切り替え。
- ゲーム、プレゼンテーション、動画が全画面表示中のディスプレイだけローテーションを一時停止。
- クイック操作で現在の壁紙を変更、エクスプローラーで表示、またはローテーションから除外。
- 除外した画像をごみ箱で確認・復元。完全削除は明示的な確認後にのみ実行。
- Windows と同時に起動し、普段の操作は通知領域から実行。
- 横向き・縦向きが混在するディスプレイを、1 つの視覚的なレイアウトで管理。

## ダウンロードと起動

[最新の MiraFolio Release](https://github.com/nexalify/MiraFolio-Windows/releases/latest) を開き、
**Assets** を展開して `MiraFolio-<version>-win-x64-portable.zip` をダウンロードしてください。現在の正式版は
`MiraFolio-1.0.0-win-x64-portable.zip` です。ZIP を任意の固定フォルダーに展開し、
`MiraFolio.exe` を実行します。インストールも別途 .NET ランタイムも必要ありません。

自動生成される **Source code (zip)** と **Source code (tar.gz)** はソースコードのアーカイブであり、Windows アプリではありません。MiraFolio は必ずこのリポジトリの公式 Releases ページからダウンロードしてください。

## モバイル版 MiraFolio

写真を中心にした壁紙体験を、デスクトップの先へ。MiraFolio は各モバイルプラットフォームに合わせてネイティブ設計され、OS に馴染む操作と自動化を提供します。

### iPhone・iPad — 配信中

お気に入りの写真を重複なしで壁紙にローテーション。スワイプでコレクションを整理し、Apple ショートカットで変更を自動化できます。プライベートな写真は保護されたアルバムに保存できます。

### Android — リリーステスト中

プレビューしてから、ホーム画面、ロック画面、または両方に直接適用できます。コレクションを自分で管理しながら、スケジュール切り替えとクイック操作を利用できます。

[Android 版を見る](https://www.mirafolio.app/ja/android/?utm_source=github&utm_medium=readme&utm_campaign=windows_mobile_cross_promo&utm_content=ja_android)

## はじめかた

1. MiraFolio を開き、ディスプレイの視覚的なレイアウトから画面を選びます。
2. その画面で使う壁紙フォルダーを選びます。
3. 切り替え間隔、再生順序、スマートマッチングのオプションを設定します。
4. ローテーションを有効にします。MiraFolio は通知領域で動作を続けます。

ほかのディスプレイも設定する場合は、最初の 3 ステップを繰り返してください。
