## Une meilleure expérience de fond d’écran sur chaque écran

- **Contrôle indépendant des écrans.** Attribuez à chaque écran son propre dossier d’images, intervalle de rotation, ordre de lecture et état d’activation.
- **Conçu pour des dizaines de milliers de fonds d’écran.** Les dossiers sont indexés en arrière-plan et les informations d’image sont mises en cache, sans relire les dimensions à chaque démarrage.
- **Triez votre collection en la parcourant.** Retirez en un clic un fond d’écran de la rotation sans supprimer le fichier source, puis restaurez-le depuis la corbeille si nécessaire.
- **Fiable quand votre configuration change.** Déconnecter un écran ne masque ni n’interrompt les autres, et tout nouvel écran peut être configuré dès que Windows le détecte.
- **Des choix d’images plus intelligents.** Associez les images paysage aux écrans paysage, les portraits aux écrans portrait et ignorez les images trop petites.
- **Confidentiel par conception.** MiraFolio fonctionne localement, sans compte, service cloud, statistiques d’utilisation ni envoi de vos fonds d’écran.

## Ce que vous pouvez faire

- Alterner les images sans répétition, dans l’ordre ou dans l’ordre inverse.
- Suspendre la rotation sur un seul écran lorsqu’un jeu, une présentation ou une vidéo passe en plein écran.
- Changer, afficher dans l’Explorateur ou retirer le fond d’écran actuel à l’aide d’actions rapides.
- Examiner les images retirées dans la corbeille, les restaurer ou les supprimer définitivement après confirmation explicite.
- Démarrer avec Windows et conserver les commandes courantes dans la zone de notification.
- Gérer les écrans paysage et portrait depuis une seule disposition visuelle.

## Télécharger et exécuter

Ouvrez la [dernière publication MiraFolio](https://github.com/nexalify/MiraFolio-Windows/releases/latest),
développez **Assets**, puis téléchargez `MiraFolio-<version>-win-x64-portable.zip`. Pour la version actuelle,
le fichier se nomme `MiraFolio-1.0.0-win-x64-portable.zip`. Extrayez le ZIP dans un dossier permanent,
puis lancez `MiraFolio.exe`. Aucune installation ni aucun environnement .NET séparé n’est nécessaire.

Les fichiers **Source code (zip)** et **Source code (tar.gz)** générés automatiquement sont des archives du code source, et non des applications Windows. Téléchargez MiraFolio uniquement depuis la page Releases officielle de ce dépôt.

## Bien démarrer

1. Ouvrez MiraFolio et sélectionnez un écran dans la disposition visuelle.
2. Choisissez le dossier de fonds d’écran associé.
3. Réglez l’intervalle de rotation, l’ordre de lecture et les options de correspondance intelligente.
4. Activez la rotation. MiraFolio continuera à fonctionner depuis la zone de notification.

Répétez les trois premières étapes pour chaque écran supplémentaire à personnaliser.

## Configuration requise

- Windows 10 ou Windows 11
- PC x64
- Aucun environnement .NET séparé pour les versions officielles autonomes
