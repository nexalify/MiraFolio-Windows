## Новые возможности обоев для каждого экрана

- **Независимое управление экранами.** Настройте для каждого монитора отдельную папку с изображениями, интервал смены, порядок воспроизведения и состояние ротации.
- **Поддержка десятков тысяч обоев.** Папки индексируются в фоновом режиме, а сведения об изображениях кэшируются, поэтому при каждом запуске не нужно заново считывать размеры файлов.
- **Упорядочивайте коллекцию во время просмотра.** Уберите неподходящие обои из дальнейшей ротации одним нажатием, не удаляя исходный файл, а при необходимости восстановите их из корзины.
- **Стабильная работа при изменении конфигурации.** Отключение одного монитора не скрывает и не прерывает работу остальных. Новые экраны можно настроить сразу после обнаружения Windows.
- **Более умный выбор изображений.** Горизонтальные изображения подбираются для горизонтальных экранов, вертикальные — для вертикальных, а слишком маленькие файлы можно пропустить.
- **Конфиденциальность по умолчанию.** MiraFolio работает локально без учётной записи, облачных сервисов, аналитики и загрузки обоев в сеть.

## Возможности

- Ротация без повторов, в прямом или обратном порядке.
- Приостановка ротации на отдельном экране, когда игра, презентация или видео развёрнуты на весь экран.
- Быстрая смена текущих обоев, открытие их расположения в Проводнике или исключение из ротации.
- Просмотр и восстановление исключённых изображений в корзине либо безвозвратное удаление только после явного подтверждения.
- Запуск вместе с Windows и повседневное управление через область уведомлений.
- Управление горизонтальными и вертикальными экранами в единой визуальной схеме.

## Скачивание и запуск

Откройте [последний релиз MiraFolio](https://github.com/nexalify/MiraFolio-Windows/releases/latest),
разверните раздел **Assets** и скачайте `MiraFolio-<version>-win-x64-portable.zip`. Текущий файл называется
`MiraFolio-1.0.0-win-x64-portable.zip`. Распакуйте ZIP в постоянную папку и запустите
`MiraFolio.exe`. Установка приложения или отдельной среды .NET не требуется.

## MiraFolio на мобильных устройствах

Если вы хотите, чтобы любимые фотографии были рядом и на телефоне или планшете, попробуйте мобильную MiraFolio. Выберите снимки, которые хотите видеть, а ротацию и порядок оставьте MiraFolio.

### iPhone и iPad

Любимых фотографий много, а на экране появляются всё те же несколько снимков? MiraFolio покажет каждую выбранную фотографию, прежде чем начать новый круг. Смахните снимок, который больше не нужен в ротации; с «Быстрыми командами» Apple обои также могут меняться каждое утро, по возвращении домой или при подключении зарядки. Личные фотографии можно хранить в отдельном заблокированном альбоме.

[Посмотреть MiraFolio для iPhone и iPad](https://www.mirafolio.app/ru/ios/?utm_source=github&utm_medium=readme&utm_campaign=windows_mobile_cross_promo&utm_content=ru_ios) ·
[Скачать в App Store](https://apps.apple.com/app/mirafolio-wallpaper-shuffle/id6791570584)

### Android

На Android фотографию можно сначала просмотреть, а затем установить на главный экран, экран блокировки или оба экрана. Настройте удобный интервал смены и переходите к следующему снимку с ярлыка на главном экране или плитки быстрых настроек, не открывая приложение каждый раз.

## Начало работы

1. Откройте MiraFolio и выберите экран на визуальной схеме мониторов.
2. Выберите папку с обоями для этого экрана.
3. Задайте интервал ротации, порядок воспроизведения и параметры умного подбора.
4. Включите ротацию. MiraFolio продолжит работать из области уведомлений.

Повторите первые три шага для всех остальных экранов, которые хотите настроить.

## Системные требования

- Windows 10 или Windows 11
- Компьютер x64
- Для официальных автономных релизов не требуется отдельная установка .NET
