## Una mejor experiencia de fondos para cada pantalla

- **Control independiente por pantalla.** Asigna a cada monitor su propia carpeta de imágenes, intervalo de rotación, orden de reproducción y estado de activación.
- **Preparado para decenas de miles de fondos.** Las carpetas se indexan en segundo plano y la información de las imágenes se guarda en caché, sin volver a leer sus dimensiones en cada inicio.
- **Organiza la colección mientras la disfrutas.** Retira con un clic un fondo que no te guste de futuras rotaciones sin borrar el archivo original, y restáuralo después desde la papelera.
- **Fiable cuando cambia tu configuración.** Desconectar una pantalla no oculta ni interrumpe las demás; las pantallas nuevas se pueden configurar en cuanto Windows las detecta.
- **Selección de imágenes más inteligente.** Combina imágenes horizontales con pantallas horizontales y verticales con pantallas verticales, y omite las imágenes demasiado pequeñas.
- **Privado desde el diseño.** MiraFolio funciona localmente, sin cuenta, servicios en la nube, analíticas ni subida de fondos.

## Qué puedes hacer

- Rotar sin repeticiones, en orden normal o inverso.
- Pausar la rotación de una pantalla concreta mientras un juego, una presentación o un vídeo está a pantalla completa.
- Cambiar, mostrar en el Explorador o retirar el fondo actual mediante acciones rápidas.
- Revisar y restaurar imágenes retiradas en la papelera, o eliminarlas definitivamente solo después de una confirmación explícita.
- Iniciar con Windows y mantener los controles habituales en el área de notificación.
- Gestionar pantallas horizontales y verticales desde una única disposición visual.

## Descargar y ejecutar

Abre la [última publicación de MiraFolio](https://github.com/nexalify/MiraFolio-Windows/releases/latest),
despliega **Assets** y descarga `MiraFolio-<version>-win-x64-portable.zip`. En la versión actual, el archivo se
llama `MiraFolio-1.0.0-win-x64-portable.zip`. Extrae el ZIP en una carpeta permanente y ejecuta
`MiraFolio.exe`. No hace falta instalar la aplicación ni un entorno .NET por separado.

Los archivos **Source code (zip)** y **Source code (tar.gz)** generados automáticamente contienen el código fuente, no aplicaciones de Windows. Descarga MiraFolio únicamente desde la página oficial de Releases de este repositorio.

## Primeros pasos

1. Abre MiraFolio y selecciona una pantalla en la disposición visual de monitores.
2. Elige la carpeta de fondos de esa pantalla.
3. Configura el intervalo de rotación, el orden de reproducción y las opciones de correspondencia inteligente.
4. Activa la rotación. MiraFolio seguirá ejecutándose desde el área de notificación.

Repite los tres primeros pasos para cualquier otra pantalla que quieras personalizar.

## Requisitos del sistema

- Windows 10 o Windows 11
- PC x64
