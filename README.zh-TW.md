## 更適合多螢幕的桌布體驗

- **每台顯示器獨立設定。** 可分別選擇圖片資料夾、輪替間隔、播放順序，以及是否啟用輪替。
- **為數萬張桌布而設計。** 資料夾會在背景建立索引並快取圖片資訊，後續啟動時不必重新讀取每張圖片的尺寸。
- **一邊欣賞，一邊整理。** 不喜歡的桌布可一鍵移出後續輪替，不會刪除原始檔案，之後也能從資源回收筒還原。
- **裝置配置變動時仍然可靠。** 中斷一台顯示器不會隱藏或打斷其他螢幕；Windows 偵測到新顯示器後也能立即設定。
- **更聰明地挑選圖片。** 橫向圖片配對橫向螢幕、直向圖片配對直向螢幕，並可略過尺寸太小的圖片。
- **隱私優先。** MiraFolio 完全在本機運作，無需帳號或雲端服務，不含分析追蹤，也不會上傳桌布。

## 你可以做什麼

- 以不重複隨機、正序或倒序方式輪替桌布。
- 遊戲、簡報或影片進入全螢幕時，只暫停對應顯示器的桌布輪替。
- 透過快速操作立即換圖、開啟目前桌布的位置，或移除不喜歡的圖片。
- 在資源回收筒檢視與還原已移除的圖片；永久刪除前一定會再次確認。
- 隨 Windows 啟動，並從通知區域完成日常操作。
- 在同一個視覺化版面中管理橫向與直向等混合螢幕配置。

## 下載與執行

開啟 [MiraFolio 最新 Release](https://github.com/nexalify/MiraFolio-Windows/releases/latest)，展開
**Assets**，下載 `MiraFolio-<version>-win-x64-portable.zip`。目前正式版檔名為
`MiraFolio-1.0.0-win-x64-portable.zip`。將 ZIP 解壓縮到固定資料夾，再執行
`MiraFolio.exe`；不需安裝，也不需另外安裝 .NET。

## 快速開始

1. 開啟 MiraFolio，在視覺化顯示器版面中選擇一台螢幕。
2. 為這台顯示器選擇桌布資料夾。
3. 設定輪替間隔、播放順序與智慧配對選項。
4. 啟用桌布輪替；MiraFolio 會繼續在通知區域中執行。

如需自訂其他顯示器，重複前三個步驟即可。

## 系統需求

- Windows 10 或 Windows 11
- x64 電腦
- 官方自包含版本不需另行安裝 .NET
